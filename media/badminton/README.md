# Humanoid badminton

Using the same training pipeline, we also trained the G1 to play badminton in simulation: Teacher reference tracking, Student distillation, and PPO fine-tuning.

- Video: `badminton-sim.mp4`, BM-034/model_38000, recorded on October 26, 2026 in MuJoCo deployment simulation; 30 seconds, 1920 × 1080, 25 FPS, real-time playback.
- Preview: `badminton-sim-preview.gif`, a 10-second excerpt starting at 3 seconds.
